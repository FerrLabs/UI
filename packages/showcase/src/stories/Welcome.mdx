# FerrLabs UI

Live showcase for **`@ferrlabs/ui/primitives`** + **`@ferrlabs/ui/react`** + **`@ferrlabs/ui-astro`**.

## Theme

Use the toolbar **Theme** picker (top of the screen) to swap the accent across the six FerrLabs products:

| Theme | Accent | Product |
|---|---|---|
| `slate` | `#1e293b` | FerrLabs (holding) |
| `orange` | `#e8733a` | FerrFlow |
| `emerald` | `#10b981` | FerrVault |
| `indigo` | `#6366f1` | FerrTrack |
| `violet` | `#7c3aed` | FerrGrowth |
| `amber` | `#f59e0b` | FerrFleet |

Every primitive consumes a single CSS token: `--color-accent`. Switching the theme in the toolbar sets `data-accent` on the preview body, which the showcase CSS resolves to one of the six product hues. In real apps, each product sets `--color-accent` once in its `global.css` — no toolbar.

## Navigation

The sidebar is grouped by package:

- **Primitives** — Wave 1 components (`Button`, `Field`, `Input`, `Textarea`, `Submit`)
- **App** *(coming)* — domain components from `@ferrlabs/ui/react` (`AppShell`, `BrandDropdown`, `AppLogoMark`)
- **Astro** *(coming)* — `@ferrlabs/ui-astro` components (`Footer`, `Navbar`, `PreFooterCTA`)

## Adding a story

Create `packages/showcase/src/stories/<ComponentName>.stories.tsx`. Storybook picks it up automatically. Use the `Meta`/`StoryObj` typed pattern from CSF3.
